# Features

This is the single feature reference for the current release candidate.

## Search and browsing

- Search Soulseek peers for artists, albums and tracks.
- Filter audio formats, bitrate, hidden users and confidently owned tracks.
- Group results by source, artist and album folder, ranked by reported upload speed.
- Browse a user's folders with artist, album and track views, searches and pagination.
- Preview a complete shared album before queuing it. Select an audio format; include shared artwork and booklets automatically.

Reported peer speeds and folder names are hints; they do not guarantee speed, a complete album, accurate tags or a specific edition.

## Downloads and uploads

- Persist single-file and album intent before engine submission.
- Prevent duplicate tracked submissions; use stable batch IDs for safe retries.
- Keep the original search and source-attempt history when recovering a failed download.
- Reconcile uncertain acceptance, then retry missing work or replace a confirmed failed source.
- Preserve album and artwork subfolders when changing source.
- Show measured progress, transfer speed and estimated time remaining.
- Clear successful download/upload entries without deleting music or hiding failures.
- See outgoing transfers, stop individual uploads, edit shared folders and block users.
- Pause/resume sharing with private configuration backups and recovery records.

## Collection

- Import the engine's stable shared-library metadata cache.
- Alternatively scan selected music folders, including unshared music.
- Retain last good tags on transient read failures; publish complete scan snapshots.
- Match collection hints against track title, artist context and duration.
- Search and page through the complete indexed collection, with independent totals.

An album-title match is a hint, not proof that every track or the same edition is owned. Collection scanning reads metadata and does not reorganise or alter music files.

## For you

- Related artists, related albums and collection gaps from the existing catalogue integrations.
- New releases matched against indexed library artists.
- Country release listings independently of the library, with genre/date/type filters.
- Cover-led cards, saved/dismissed discoveries, publisher-labelled critic scores and article previews.
- Artwork fallback from existing publisher images, Apple, Deezer and Cover Art Archive where identifiers are known.
- Review and release-feature lookup from the already-connected publications, with separate source labels and original links.

Online discovery is optional. Caches remain usable offline. Release lists are editorial selections rather than a complete worldwide release database; missing reviews, artwork and genres remain possible. Original release dates and editions are shown with their available confidence. No review or score is invented. Publisher previews are not a synthesized original review.

## Chat and diagnostics

- Soulseek private conversations from user pages and transfer/search results.
- Persistent, redacted error history and a downloadable diagnostic report.
- Demo data for exploring the interface without sending messages or starting transfers.
- Local-only service access, session-protected changes and private first-time configuration.
